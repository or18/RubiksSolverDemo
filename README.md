# RubiksSolverDemo

An experimental research and demonstration project featuring specialized Rubik's Cube solvers and customized scramblers. 

It provides IDA* search and precomputed pattern database solvers for 3x3x3 stages (Cross, XCross, Free Pair, Pseudo F2L, EOCross, and Last Layer), as well as an optimal 2x2x2 solver.

### Web Applications
- [**3x3x3 Solver**](https://or18.github.io/RubiksSolverDemo/)
- [**2x2x2 Solver**](https://or18.github.io/RubiksSolverDemo/2x2x2.html)
- [**Legacy Version**](https://or18.github.io/Rubiks-cube-xcross-solver/)
